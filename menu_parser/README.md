# Распознавание меню по фото (Gemma)

## Через сайт GitHub — без установки чего-либо

1. Откройте на GitHub папку `menu_parser/photos` → **Add file → Upload files**.
2. Перетащите **папку** с фото меню, названную латиницей — это будет id кофейни, например `kofe_house` (внутри — jpg/png страниц меню). Можно положить туда и `cafe.json`:
   ```json
   { "name": "Kofe House", "city": "Алматы", "address": "ул. Абая, 1", "hours": "до 22:00" }
   ```
3. Нажмите **Commit changes**. Запустится задача «Меню из фото» (вкладка **Actions**): распознает фото, добавит кофейню на сайт и опубликует его. Через 2–3 минуты меню будет по адресу `https://the-fabulous.github.io/secretbox_menus/?cafe=kofe_house`.
4. Добавили или заменили фото в той же папке — меню этой кофейни распознается заново из всех её фото.

Меню, сделанные вручную (Master Coffee, AYU и т.п.), задача не перезаписывает: результат можно скачать на странице задачи (Actions → задача → Artifacts → `menu-json`).

Нужен один раз: секрет `OPENAI_API_KEY` с ключом Gemma — Settings → Secrets and variables → Actions → New repository secret.

## На своём компьютере

`driver.py` отправляет фото меню в Gemma (llm.alem.ai) и собирает JSON для сайта — в том же формате, что `coffee-menu/cafes/master_coffe.json`. Пустой шаблон формата — `etalon.json`.

### Подготовка (один раз)

```powershell
cd menu_parser
pip install -r requirements.txt
```

Откройте `.env` и вставьте ключ после `OPENAI_API_KEY=`. Файл `.env` не попадает в Git — не переименовывайте его и не кладите ключ в другие файлы.

### Запуск

1. Положите фото страниц меню в отдельную папку, например `photos/ayu/` (jpg, png, webp).
2. Запустите:
   ```powershell
   python driver.py photos/ayu --cafe-id ayu_menu
   ```
3. Результат — `output/ayu_menu.json`. Сырые ответы модели по каждому фото — в `output/raw/ayu_menu/` (если что-то распознано не так, смотрите туда).
4. Проверьте цены и названия и скопируйте файл в `coffee-menu/cafes/`. Если это новая кофейня — добавьте её в `coffee-menu/data/cafes.json`.

Можно сразу сохранить в папку сайта: `--out ../coffee-menu/cafes/ayu_menu.json` (существующий файл будет перезаписан).

### Что делает скрипт с ответом модели

- цены приводит к числам («1 290 ₸» → 1290), позиции без цены пропускает и пишет об этом;
- всё, чего нет на фото (описание, состав, КБЖУ, время), оставляет `null`;
- разделы — только из `coffee-menu/data/categories.json`, незнакомые — в `other`;
- одинаковые позиции с разных фото не дублирует;
- id позиций строит из названия латиницей, пути к фото — `pictures/items/<кофейня>/<id>.jpg`.
