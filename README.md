# Secretbox — меню кофеен

Сайт: https://the-fabulous.github.io/secretbox_menus/

## Добавить или обновить заведение

Откройте **[venues/](venues/)**: внутри находится отдельная папка каждого заведения с `cafe.json` и скриншотами меню. Здесь загружаются исходные файлы; обработчик находится в `menu_parser/`, готовый сайт — в `coffee-menu/`.

Готовая вкладка целиком лежит в **`coffee-menu/tabs/<id>/`**: `cafe.json` (название и сведения), `menu.json` (меню), `images/` (фото позиций), `logo.*` (если есть логотип). `tabs/index.json` содержит только бренд и список папок. Общие стили и код интерфейса используются всеми вкладками.

Локально из корня проекта: `python menu_parser/driver.py venues/master_coffee`. Драйвер создаёт или обновляет папку вкладки и сам добавляет её в список сайта. Для отдельной копии: `--out menu_parser/output/tabs/master_coffee`.

Пример: `venues/dodo_pizza/cafe.json` задаёт название и сведения о заведении, а изображения рядом — его меню. [Инструкция и пример конфига](venues/README.md).

## Загрузка через сайт

`coffee-menu/admin.html` — панель сотрудников: общий пароль, выбор исходной папки, проверка конфига и наблюдение за обработкой. Ссылка «Управление меню» появляется в режиме `?staff=1`. Перед первым использованием нужно развернуть сервер панели и указать `admin_api_url`: [настройка и права доступа](menu-admin/README.md). Панель создаёт только новые заведения, существующие вкладки не перезаписываются.

## Приложение и публикация

Исходники приложения находятся в `coffee-menu/`. Инструкции по данным и локальному запуску: [coffee-menu/README.md](coffee-menu/README.md).

GitHub Actions публикует содержимое `coffee-menu/` в GitHub Pages при каждом push в `main`. В Settings → Pages источник публикации должен быть **GitHub Actions**.
