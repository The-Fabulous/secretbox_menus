# Фото меню → целая вкладка

Драйвер отправляет изображения из `venues/<id>/` в Gemma и собирает одну папку заведения:

```text
coffee-menu/tabs/
  index.json                 # бренд и список папок вкладок
  master_coffee/
    cafe.json                # название, адрес, часы, оформление
    menu.json                # разделы, позиции, цены, добавки
    logo.png                 # если указан в исходном cafe.json
    images/                  # вырезанные фото позиций (если найдены)
    raw/                     # ответы модели для проверки; не входят в Git
```

Имя папки — стабильный id из имени исходной папки (`master_coffee`, `dodo_pizza`). Название для сайта задаётся в `cafe.json`, например `"name": "Master Coffee"`. Пути к фото и логотипу относительны папке вкладки. Общий интерфейс и стили остаются в `coffee-menu/`.

## Через GitHub

1. Загрузите папку с `cafe.json` и изображениями в `venues/` через **Add file → Upload files**.
2. Сохраните изменения. Задача «Меню из фото» создаст папку вкладки, обновит `tabs/index.json` и опубликует сайт.
3. Новые исходники в той же папке обновляют то же заведение. Ссылка остаётся `?cafe=<id>`.

Нужен секрет репозитория `OPENAI_API_KEY`. Вкладки без `"source": "photos"` в готовом `cafe.json` считаются ручными и не перезаписываются. Результат для них доступен отдельной папкой в артефакте `menu-tabs`.

## Локально

Из корня проекта:

```powershell
pip install -r menu_parser/requirements.txt
python menu_parser/driver.py venues/master_coffee
```

Ключ хранится в `menu_parser/.env` (`OPENAI_API_KEY=...`). По умолчанию результат сразу попадает в `coffee-menu/tabs/master_coffee/` и регистрируется в списке сайта. Публикация в интернете происходит после отправки изменений в GitHub.

Для отдельной папки без добавления на сайт:

```powershell
python menu_parser/driver.py venues/master_coffee --out menu_parser/output/tabs/master_coffee
```

`--out` принимает **папку**, а не отдельный JSON. Чтобы добавить проверенную копию на сайт, перенесите всю папку в `coffee-menu/tabs/` и добавьте её имя в массив `tabs` файла `tabs/index.json`. Старый флаг `--publish` оставлен для совместимости; запись на сайт теперь включена по умолчанию.

## Распознавание

- JPG, JPEG, PNG, WebP и BMP лежат непосредственно в папке заведения.
- `logo` в исходном `cafe.json` задаёт имя файла логотипа рядом с меню. Драйвер копирует его и исключает из распознавания.
- Длинные скриншоты режутся на фрагменты с перекрытием; повторяющиеся позиции объединяются.
- Цены приводятся к числам, неизвестные сведения остаются `null`, позиции без распознанной цены пропускаются с предупреждением.
- Фото позиций сохраняются в `images/`; `--no-photos` отключает их поиск и вырезание.
- Если запрос по любому фрагменту завершился ошибкой или меню получилось пустым, готовая вкладка не изменяется.
- Проверьте цены и названия после распознавания. Ответы модели лежат рядом в `raw/`.

Шаблон JSON — `etalon.json`, общие категории — `coffee-menu/data/categories.json`.
