# Заведения: конфиг и скриншоты меню

Для каждого заведения создайте отдельную папку здесь. Имя папки — постоянный id латиницей в нижнем регистре, без пробелов, например `coffee_house`.

```text
venues/
  dodo_pizza/
    cafe.json
    menu-1.jpg
    menu-2.jpg
  master_coffee/
    cafe.json
    menu-1.jpg
```

Положите `cafe.json` и изображения непосредственно в папку заведения. Поддерживаются JPG, JPEG, PNG, WebP и BMP. Имена изображений могут быть любыми.

Пример `cafe.json`:

```json
{
  "name": "Кофейня Зёрнышко",
  "address": "ул. Абая, 1",
  "city": "Алматы",
  "hours": "08:00–22:00",
  "logo": null
}
```

`name` — название на странице заведения. Если конфиг отсутствует, название берётся из имени папки. `logo` — путь к существующему логотипу относительно `coffee-menu/`; при отсутствии укажите `null`. Логотипы храните в `coffee-menu/pictures/logos/`, чтобы распознаватель не считал их страницами меню.

Загрузите папку заведения через GitHub → `venues` → **Add file → Upload files**, затем сохраните изменения. Workflow «Меню из фото» обработает скриншоты через Gemma и при успешной обработке опубликует меню. Требуется секрет репозитория `OPENAI_API_KEY`.

Изменение скриншотов или `cafe.json` повторно запускает распознавание всех изображений этого заведения. Готовые данные находятся в `coffee-menu/cafes/`, список заведений — в `coffee-menu/data/cafes.json`. Меню, созданные вручную, автоматически не перезаписываются.

Прямая ссылка на заведение: `https://the-fabulous.github.io/secretbox_menus/?cafe=coffee_house`.

Настройки модулей доставки и самовывоза пока не реализованы. Текущий конфиг описывает название и сведения о заведении.
