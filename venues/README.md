# Заведения: конфиг и скриншоты меню

Для каждого заведения создайте отдельную папку здесь. Имя папки — постоянный id латиницей в нижнем регистре, без пробелов, например `coffee_house`.

```text
venues/
  dodo_pizza/
    cafe.json
    menu-1.jpg
    menu-2.jpg
  master_coffee/
    cafe.json
    menu-1.jpg
```

Положите `cafe.json` и изображения непосредственно в папку заведения. Поддерживаются JPG, JPEG, PNG, WebP и BMP. Имена изображений могут быть любыми.

Пример `cafe.json`:

```json
{
  "name": "Кофейня Зёрнышко",
  "address": "ул. Абая, 1",
  "city": "Алматы",
  "hours": "08:00–22:00",
  "logo": null
}
```

`name` — название на странице заведения. Если конфиг отсутствует, название берётся из имени папки. `logo` — имя файла логотипа рядом с исходниками, например `logo.png`; при отсутствии укажите `null`. Указанный логотип копируется в готовую вкладку и не отправляется на распознавание как страница меню. Старые пути от корня `coffee-menu/` тоже поддерживаются.

Загрузите папку заведения через GitHub → `venues` → **Add file → Upload files**, затем сохраните изменения. Workflow «Меню из фото» обработает скриншоты через Gemma и при успешной обработке опубликует меню. Требуется секрет репозитория `OPENAI_API_KEY`.

Изменение скриншотов или `cafe.json` повторно запускает распознавание всех изображений этого заведения. Готовая вкладка целиком находится в `coffee-menu/tabs/<id>/`: сведения в `cafe.json`, меню в `menu.json`, фотографии в `images/`, логотип рядом. Список папок — `coffee-menu/tabs/index.json`, драйвер обновляет его сам. Меню, созданные вручную, автоматически не перезаписываются: отдельная готовая папка сохраняется в `menu_parser/output/tabs/<id>/` (в GitHub Actions — артефакт `menu-tabs`).

Прямая ссылка на заведение: `https://the-fabulous.github.io/secretbox_menus/?cafe=coffee_house`.

## Опциональные самовывоз и доставка (демо)

Добавьте в `cafe.json` блок `modules`. Драйвер перенесёт его в готовую вкладку без участия модели:

```json
"modules": {
  "pickup": {
    "enabled": true,
    "ready_minutes": 20,
    "address": "Адрес точки самовывоза"
  },
  "delivery": {
    "enabled": true,
    "fee": 700,
    "min_order": 2000,
    "free_from": 10000,
    "travel_minutes": 30
  }
}
```

Каждый модуль включается независимо, только при `enabled: true`. Если блока нет или стоит `false`, соответствующего способа в корзине нет. Удаление `modules` из исходного конфига отключит оба модуля при следующем запуске драйвера. «В зале» и обычное «С собой» остаются доступны.

Самовывоз показывает точку выдачи (поле `pickup.address`, иначе адрес заведения), телефон и выбор времени. `ready_minutes` — минимальный ориентир готовности, учитывается также время приготовления блюд.

Доставка запрашивает адрес и телефон. Суммы заданы в валюте заведения: `fee` — доставка, `min_order` — минимум стоимости товаров без доставки, `free_from` — порог бесплатной доставки (можно опустить). `travel_minutes` добавляется к времени приготовления. Значения в примере — демонстрационные, это не реальные тарифы Master Coffee.

Оба сценария явно помечены как демо: заказа у заведения не появляется, оплаты и курьеров нет. Заказ и введённые контакты сохраняются только в истории браузера. Проверка реального адреса, зоны доставки, часов работы и свободных интервалов не выполняется.
